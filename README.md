# Space-Invaders 
A modern take on the classic arcade shooter, built from scratch using C++ and the Simple and Fast Multimedia Library (SFML). This project combines retro-inspired gameplay with robust object-oriented design, efficient resource management, and immersive audiovisual feedback. Perfect for showcasing core game development principles and SFML’s capabilities in handling real-time interactive applications.
<h3>Video - https://www.youtube.com/watch?v=kgfeGIyMsJc </h3>
<h3>Features</h3>
<ul>
  <li>Utilized MVC architecture, Service Locator pattern, and OOP principles for a modular and maintainable codebase.</li>
<li>Optimized performance using object pooling and efficient rendering techniques for smooth gameplay.</li>
<li>Integrated animations, particle effects, and sound effects to enhance the user experience. </li>
</ul>
